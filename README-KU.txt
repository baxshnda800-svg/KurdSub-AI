KurdSub AI — وەشانی فرەزمانە بە Gemini API

چی دەکات؟
- فایلە دەنگی و ڤیدیۆییەکان لە مۆبایل و کۆمپیوتەر وەردەگرێت.
- زمانی قسەکردن بە شێوەی خۆکار دەناسێتەوە؛ یان دەتوانیت زمانی سەرچاوە دیاری بکەیت.
- ژێرنووس بۆ زمانێکی هەڵبژێردراو وەردەگێڕێت؛ دەتوانیت ناوی زمانێکی تر بنووسیت.
- دەقی سەرەکی، وەرگێڕان و کاتەکان نیشان دەدات؛ دەستکاری و دابەزاندنی SRT هەیە.
- تەنیا یەک API key پێویستە: GEMINI_API_KEY. کلیلەکە لە سێرڤەر دەمێنێتەوە و بۆ بەکارهێنەر نیشان نادرێت.
- لینکی گشتیی YouTube بە شێوەی preview ڕاستەوخۆ وەردەگرێت لە ڕێگەی Gemini Interactions API.

سنوور و تێبینی:
- تایبەتمەندیی YouTube URL لەلایەن Google وەک preview ناسێنراوە؛ ڤیدیۆی گشتی بەکاربهێنە. ڤیدیۆی تایبەت، پارێزراو یان هەندێک لینک لەوانەیە کار نەکات. نرخ و سنووری بەکارهێنان دەتوانێت بگۆڕێت.
- لینکەکانی TikTok ڕاستەوخۆ پشتگیری ناکرێن؛ ئەگەر مۆڵەتت هەیە، فایلەکە لە ئامێرەکەت پاشەکەوت بکە و لە گەلەری باربکە.
- فایلە بارکراوەکان لەم وەشانەدا تا 18MB ـن. ڕێگای inline بۆ کلیپی کورت گونجاوترە؛ بۆ ڤیدیۆی درێژ، بە پارچەی کورت دایبەزێنە. ئەم وەشانە هێشتا سیستەمی File API بۆ بارکردنی ڤیدیۆی زۆر درێژ نییە.
- کاتەکانی ژێرنووس کە لەلایەن مۆدێلەوە دیاری دەکرێن دەتوانن هەڵەیان تێدا بێت. پێش بەکارهێنان یان بڵاوکردنەوە، دەق و کاتەکان پێداچوونەوەیان بکە.
- Gemini پشتگیریی زمانە زۆرەکان دەکات، بەڵام وردی بەپێی زمان، شێوازی قسەکردن و کوالێتی دەنگ دەگۆڕێت.
- API key هەرگیز لە HTML/JavaScript، GitHub repository یان چاتدا مەخە. تەنیا لە Environment ـی سێرڤەر دایبنێ.
- بەکارهێنانی Gemini لەوانەیە free quota، rate limit یان تێچووی هەبێت. پلانی هەژمارەکەت پێش بەکارهێنانی زۆر بپشکنە.
- ئەمە سەرچاوەی پڕۆژەیە، نەک وێبسایتێکی بڵاوکراوە. پێویستە deploy بکرێت و پاشان تاقی بکرێتەوە.

دروستکردنی Gemini API Key:
https://aistudio.google.com/app/apikey

بڵاوکردنەوە بە iPhone:
1. ZIP ـەکە لە Files ـی iPhone دابەزێنە و لەسەری کرتە بکە تا فولدەرەکە بکاتەوە.
2. لە GitHub هەژمار دروست بکە یان بچۆ ژوورەوە؛ repository ـێکی نوێ دروست بکە بە ناوی KurdSub-AI.
3. فایلەکانی پڕۆژەکە بۆ repository ـەکە upload بکە؛ فولدەری static و فایلەکەی index.html لەناویدا بپارێزە.
4. لە Render هەژمار دروست بکە و New > Blueprint هەڵبژێرە؛ repository ـەکە پەیوەست بکە.
5. لە Environment ـی خزمەتگوزاری Render، GEMINI_API_KEY زیاد بکە و کلیلەکەت تێدا دابنێ. کلیلەکە لە GitHub مەخە.
6. Deploy بکە. دوای تەواوبوونی deploy، URL ـەکە لە Safari بکەرەوە و /api/health تاقی بکەرەوە؛ دەبێت configured=true بێت.
7. پاشان بە کلیپێکی کورت تاقی بکەرەوە و وردی ژێرنووسەکان بپشکنە.

ڕێکخستنی Render:
Build command: pip install -r requirements.txt
Start command: uvicorn main:app --host 0.0.0.0 --port $PORT

Model ـی بنەڕەتی: gemini-3.8-flash
دەتوانیت لە Render Environment ـدا GEMINI_MODEL بگۆڕیت، بەڵام تەنیا بە ناوی مۆدێلێکی بەردەست.
