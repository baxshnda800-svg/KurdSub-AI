١ ڤیدیۆ هەڵبژێرە

لینکی گشتیی YouTube دەتوانرێت ڕاستەوخۆ تاقی بکرێتەوە لە ڕێگەی تایبەتمەندیی preview ـی Gemini. ئەم تایبەتمەندییە لەوانەیە سنوور یان گۆڕانکاریی هەبێت؛ ڤیدیۆی تایبەت و هەندێک لینک کار ناکەن.

لینکی TikTok ڕاستەوخۆ پشتگیری ناکرێت. ئەگەر مۆڵەتت هەیە، ڤیدیۆکە لە ئامێرەکەت پاشەکەوت بکە و لە بەشی گەلەری هەڵیبژێرە.

٤ زانیاری

ئەم وێب‌ئەپە Gemini API بەکاردەهێنێت بۆ ناسینەوەی دەنگ و وەرگێڕان. کلیلەکە تەنیا جارێک لە سێرڤەری پارێزراو دادەنرێت و لە ئەپەکەدا نیشان نادرێت. لینکی گشتیی YouTube بە شێوەی preview پشتگیری دەکرێت؛ TikTok پێویستی بە بارکردنی فایلەکەیە. فایلە بارکراوەکان لەم وەشانەدا تا 18MB ـن و بۆ کلیپی کورت گونجاون؛ بۆ ڤیدیۆی درێژ، بە پارچەی کورت دایبەزێنە. وردی کات و وەرگێڕان دەتوانێت پێویستی بە دەستکاریکردن هەبێت. بەکارهێنانی Gemini لەوانەیە سنووری خۆڕایی یان تێچووی هەبێت؛ پلانی هەژمارەکەت بپشکنە.
